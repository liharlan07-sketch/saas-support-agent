# 退货期限
在这个虚构商家的示例规则中，普通退货申请期限为签收后七天；以订单记录的签收日期为准。
# 超期退货
退货超过申请期限时，商家可以创建售后工单，说明超期原因并提供签收凭证，由人工核对。提交工单不表示批准退货或自动退款。
# 未签收包裹
包裹尚未签收时，先查询物流状态；显示异常或疑似遗失时，应提交物流异常说明。
# 商品破损
签收后发现破损时，提交商品、包装和面单照片，并说明破损部位，等待人工核验。
# 错发商品
收到商品与订单规格不一致时，记录实际收到的规格和订单规格，保留商品照片以供核对。
# 退货寄回
人工确认可退货后，按工单中提供的退货地址寄回，并填写实际运单编号。
# 拒收说明
买家拒收时，先核对拒收记录和物流回流状态。拒收不等于退货已完成。
# 无法提供凭证
缺少签收凭证时，可提交已有物流截图和情况说明，由人工决定是否需要补件。
# 工单状态
待人工受理只表示售后请求已经登记。商家可用工单编号查询，不代表已经批准或退款。
# 重复工单
同一售后问题已提交时，优先按已有工单编号查询，避免重复描述同一问题。
